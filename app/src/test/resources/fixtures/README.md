# Parser fixtures

These synthetic HTML contracts come from the reference application's parser tests. They exercise the known selected-courses URL pattern, Georgian/English headings, nullable grades, grade components, and same-origin resource filtering. Student and lecturer labels are test values. No cookies, credentials, or live student records are included.

They are regression fixtures, not evidence that course-detail HTML has been captured from a live authenticated account. Further modules need separately inspected, sanitized responses before adding native parsers.
